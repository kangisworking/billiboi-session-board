# message-board

세션 간 메시지(SendMessage 로 주고받은 것)와 사용자가 각 세션에 입력한 프롬프트를 한 타임라인으로 보여 주는 모드입니다. `session-board` 의 짝으로, 같은 표·색 체계를 씁니다.

```
메시지 12/12 · 전체
── 2026-01-02 ───────────────────────────────────────
09:05 ●나 → ●A · 조율 (입력)
  리뷰 끝나면 알려 줘
09:06 ●A · 조율 → ●B · 리뷰어
  리뷰 부탁. 아주 긴 본문이 이어집니다. 아주 긴 본문이 이어집니다. 아주 긴
  본문이 이어집니다. 아주 긴 본문이 이어집니다. 아주 긴 본문이 이어집니…
── 2026-01-03 ───────────────────────────────────────
09:05 ●B · 리뷰어 → ●A · 조율
  리뷰 끝. 두 군데 고칠 곳 있음
```

## 어떻게 동작하나

세션 간 메시지는 디스크에 따로 남지 않고 각 세션의 대화 기록(jsonl) 안에만 있습니다. 그 파일은 크고(수십 MB) 모드가 읽을 수 있는 한도(4 MiB)를 넘으므로, 이 모드는 **각 세션이 자기 메시지를 직접 남기는 방식**을 씁니다. 그래서 타임라인에 올라오려면 **메시지를 주고받는 세션마다 이 모드가 켜져 있어야** 합니다.

기록(이 모드를 켠 세션마다):

| 훅 | 남기는 것 |
|---|---|
| `session.send` | 이 세션이 보낸 메시지(SendMessage 도구, 다른 플러그인의 `$.session.send`) |
| `session.receive` (origin `peer`) | 다른 세션에서 받은 메시지. 봉투의 `from` 주소를 보낸이로 |
| `prompt.submit` (origin `composer`) | 사용자가 이 세션에 직접 입력한 프롬프트. 슬래시 명령과 메타 입력은 제외 |

파일: `~/.claude/peer-status/messages/<YYYY-MM-DD>/<ts>-<sessionId 앞 6자>-<out|in|user>.json`, 한 건 한 파일.

```json
{ "id": "1767312300000-a1b2c3-out", "ts": 1767312300000, "dir": "out",
  "from": "session:a1b2c3d4-...", "to": "uds:/tmp/cc-socks/4242.sock", "text": "리뷰 부탁" }
```

- `text` 는 앞 **500자**만 남깁니다(공백은 한 칸으로).
- 날짜 폴더는 **7일**이 지나면 세션 시작 때 지웁니다(`messages/` 아래 날짜 이름 폴더만).
- 보낸 쪽과 받은 쪽이 같은 메시지를 둘 다 남기면 보낸이·받는이·본문 앞 200자가 같고 10분 안인 것을 하나로 합칩니다.

표시: 5초마다 폴더를 읽어 최신이 아래로 오게 그립니다. 보낸이·받는이는 `session-board` 와 같은 `aliases.json` 으로 역할 이름을 붙이고(`uds:/…/<pid>.sock` 주소는 그 pid 의 세션으로 풀어서), 이름마다 고정 색 점 `●` 을 둡니다. 사용자가 입력한 것은 보낸이 `나`, 뒤에 `(입력)`.

## 명령

| 명령 | 동작 |
|---|---|
| `/message-board` | 패널로 열기(기본). 전체화면이면 오른쪽, 아니면 프롬프트 위 inline |
| `/message-board band` | 프롬프트 위 띠에 최근 5건만. 띠는 플러그인 하나만 그릴 수 있어 `session-board` 띠와 같이 켜면 둘 중 하나만 보입니다. 함께 쓰려면 `session-board` 의 최근 메시지 칸(`/session-board msgs on`)을 쓰세요 |
| `/message-board off` | 숨기기 |
| `/message-board from <이름>` | 보낸이에 그 글자가 들어간 것만 |
| `/message-board to <이름>` | 받는이에 그 글자가 들어간 것만 |
| `/message-board me` | 내가 입력한 것만 |
| `/message-board all` | 필터 풀고 패널로 |
| `/message-board expand` | 본문 2줄 ↔ 전부(토글) |

## 설치

```
/plugin install message-board --marketplace kangisworking/billiboi-session-board
```

또는 `claude --plugin-dir <이 폴더>` / `CLAUDE_CODE_PLUGIN_DIRS`. **메시지를 주고받는 세션 모두**에 켜 둡니다. 어느 한 세션에만 켜면 그 세션이 보내고 받은 것만 보입니다.

## 개인정보·보안

- 로컬 파일(`~/.claude/peer-status/messages/`)에만 남고 어디에도 보내지 않습니다.
- 메시지 본문 앞 500자와 사용자가 입력한 프롬프트 앞 500자가 평문으로 남습니다. 비밀값을 메시지나 프롬프트에 적지 않도록 하고, 필요하면 폴더를 지우면 됩니다.
- 세션 대화 기록(jsonl)은 읽지 않습니다. 쓰는 곳은 위 폴더 하나이고, 지우는 것도 그 아래 7일 넘은 날짜 폴더뿐입니다.
